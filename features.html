Architecture

The website markets AutoTrade. The app runs it.

Every feature above lives inside the AutoTrade Windows application — the website's role is plans, payment, download, and account information.

Note: AutoTrade does not execute trades from this website. All strategy execution happens in the downloadable Windows desktop application, connected to your supported broker.
